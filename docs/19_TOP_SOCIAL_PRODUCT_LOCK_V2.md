# SOCIAL TOP V2 — PRODUCT RULES, DATA QUALITY & OPERATIONS
Status: game product baseline; backend not built. Rules are time-neutral, online competition asynchronous and optional.

## Four separate motivations
1. Personal records in Casual: last rung, boards completed, biggest combo, score within standardized 40-swap window and no-assist clears. Offline by default; raw lifetime score NEVER goes on Global Top.
2. Shared challenge: all people get an identical board/queue/ruleset for the same game and challenge ID. Time spent thinking NEVER counts.
3. Family Club: invite by short code, opt-in pseudonyms, Top for same official pack. No direct messages, phone access or public age categories.
4. Achievements: visual flowers/postcards for strategic milestones and game mastery, NO calendar attendance penalty or energy system.

## Start with SHORT daily + longer weekly
- LINK: **1 board / day**, 5 boards / week. Same 6x8 size. The earlier five-board daily design is superseded to avoid 240+ required tile taps for one daily.
- BUBBLE: **1 board / day**, 3 / week. Max 60 valid shots each; NO time clock, score reflects successful pop/detach/unused shots for cleared boards.
- JEWEL: **20 valid swaps / daily**, 40 / weekly. All play is at individual's pace. Scores with different action allowances NEVER share a ranking.
- Optional three-official-attempt policy (3 per challenge pack, BEST accepted score; practice uses **different seeds of equivalent band**, not official pack). A player can stop halfway and resume. If season closes, continue that board privately but official Top freezes at declared deadline, including a clear post-close grace interval.
- Scores are integers and verified server-side by replay. Rank with standard competition ranks (1,2,2,4), ties share position. Never silently order a tie by milliseconds.
- Percentile badges only after minimum pool size and closed weekly pack; avoid falsely significant percentile in a club of 3 friends.

## Top design anti-exploitation
An unlimited-practice look at the exact ranked seed undermines a three-attempt limit. Therefore practice shares rule/difficulty and cosmetics but NOT the published official seed. Users may of course memorize or solve boards externally; this is a friendly skill leaderboard, NOT a cheat-proof sport.
For each game, simulate 100+ strategies/boards before freezing rank rules: naive, careful, greedy, solver-like, hint-happy, and deliberately abusive undo/restart. Report unique score count, tie-at-ceiling %, completion %, median official-move count and effect of assists. If over 40% of eligible completions tie at maximum, STOP and redesign the scoring test before public launch; NEVER add timer tiebreak.
- Casual Undo unlimited; Ranked fee irreversibly appended to assistLedger. Replaying an undone match must not count score twice.
- Reshuffles reduce score and consume a deterministic published sequence. Score cannot go below zero; fee ledger retained even after restoring board.
- Bubble and Jewel randomness must follow the exact same seed+action replay on client/server; the player may pick divergent routes, not divergent hidden PRNG.

## Attempt lifecycle (server status)
DRAFT (not counted) -> STARTED (counted official attempt only after confirmed Start) -> PAUSED_LOCAL (resumable) -> SUBMITTED -> PENDING_REPLAY -> ACCEPTED / REJECTED. Completed season -> PRACTICE_ONLY; must never delete local saved run. Client may retry upload with same idempotency key; backend accepts once and never increments attempt count twice.
Server authenticates pseudonymous user, issues signed run token, validates challenge/version/open period and replay log, computes score independently, stores best verified submission; requires rate-limits and alerts. Synthetic replay-valid logs generated by an external solver cannot be distinguished reliably from a human; no cash or valuable prizes and no "cheat-proof" claims.

## API and online service minimum
HTTPS; guest opaque ID with opt-in account recovery; signed immutable challenges; indexed score database and run logs with bounded retention; stable ranking pagination; invitation code brute-force rate-limit; profanity filter/display pseudonyms; backup and disaster restore rehearsal; moderation/delete/export GDPR workflow. Avoid storing raw names, ages, address books or contact lists.
Challenge publisher runs: generator -> proof/witness -> deterministic replay -> score distribution stress -> approve immutable challenge artifact + hash -> schedule -> publish -> monitor -> archive. If generation fails, publish an explicitly certified fallback pack, not untested random data. If server offline, Free Play still works.

## Eligibility and time-zone reality
Daily "calendar day" and weekly period are anchored by server UTC (with local Paris display conversion including DST). Date is used for submission windows only; the act of THINKING never expires or causes a loss. Publish cutoff and grace window in UI. No push alert pressure. Accessibility and full offline progress stay intact.

## Metrics before global Top greenlight
>=100 certified pack simulations/mode and representative strategy scores, >=12 adult hands-on tests across all 3 modes, beta family club (prefer 5+ volunteer users) and actual backend replay rejection tests. Zero fraudulent score acceptance in known injected cases, deterministic hash parity 100%, explicit duplicate submission tests. Top launch cannot be PASS based on API mockups.
