# GAME 2 — BUBBLE ORCHARD | BẮN BÓNG
Status: DESIGN V1, NOT IMPLEMENTED.

## How to play
A launcher at bottom fires one colored bubble per deliberate tap. Aim with visible dotted prediction path (including ONE wall reflection or more if valid); touch and hold to adjust, release/tap Shoot. Bubble attaches on staggered hex grid to the first physically contacted occupied bubble or ceiling. Matching >=3 connected same-colored bubbles removes the group. Any group no longer connected to ceiling falls and counts bonus. No bubble moves because of REAL TIME.

## Input & accessibility
Big launcher button optional: tap anywhere to set target angle; press large SHOOT to fire (no precision drag required). Show 2 upcoming colors. Fixed camera, slow controllable animation 150–300ms, reduced-motion instant resolve; trajectory predictable to wall including bounce. Optional visual guide/no sound. No surprise aim sway or timer. Prevent taps while shot is resolving, but process input quickly.

## Grid, collision, deterministic rules
Prototype grid 9 bubbles across, 11–13 visible staggered rows, radius/spacing constants defined in data and locked per ruleset. Symmetric projectile collision with first hit; when multiple snap cells equidistant, deterministic ordering (distance then row then column); snap to a valid neighbor; ceiling snap if reached. All bubbles have one of 5 colors initially. 4-neighbor? NO: staggered hex has up to SIX neighbors with odd/even row offsets. Clearing >=3 connected identical colors flood-fill; then BFS from ceiling identifies detached clusters and removes them. Do not treat rendered pixels as physics collision; fixed logical grid and path raycast determine state.
Shot color queue generated by deterministic PRNG per seed. In initial MVP, limit candidate colors to those still present on board when needed, avoiding impossible-color punishment. Full queue revealed current + next two.

## Free Play endless
Every 12 launched shots, if game still running, add ONE seeded top row and shift logical grid down (this is an effect of **actions only**, never inactivity); parameter adjustable based on tests. Ceiling arrival or occupied cell crosses visible danger line after resolving a shot => run ends; report score and let player rematch, not erase earned milestones. Clearing the entire board awards a garden bloom and generates next seed board automatically while preserving current run score. Long-run PB is strategic survival under limited area, not elapsed time.
Prototype score: 10 per matched/popped bubble, +30 per detached bubble, +50 per 1-bank-shot successful clear, +50 for fully cleared board. Bank-shot bonus only when user genuinely banked off wall and clears >=3; award once per shot. Every 1000 score unlocks a personal milestone; no max level.

## Ranked
Same 3 board seeds + same shot queue; 60 maximum shots per board (not seconds). Score +10 per popped, +30 detached, +20 per unused shot on completely cleared board. Bank-shot score can be separately added only if it is deterministic and QA-tested. The board ends upon full clear, after 60 shots, or if danger line is crossed; no sudden time loss. Best of 3 runs on shared pack; server replay checks all aiming angles quantized as e.g. 1/1024 turn, snap order, group removal and queue sequence. If actual physics drifts across devices, online fairness FAIL: use integer/fixed-point grid path collision rather than uncontrolled framerate physics.

## Skill and depth without reaction speed
- Plan which color chain to attack, when to bounce off a wall and when to disconnect a large group.
- Avoid constantly shooting at same color with no strategy.
- Show clear danger indicators; falling rows only after shot counter advances, and an icon indicates when next row is due.
- The level's novelty comes from cluster layout, blocked angles and target grouping; no camera motion/pressure countdown.

## Generator & QA
Generate reachable attached cluster layouts using seeded layouts, preserve at least one plausible clear path, evaluate solvability with finite planned shot queues and coarse angle search/beam solver for ranked. For ranked, create boards by reverse or solver-guided constructive methods, reject those with no practical completion route under 60 shots. For Casual, allow retry if board fills; never claim every possible aiming sequence can finish.
Tests: direct hit, edge hit, wall bounce, ceiling snap, snap tie, detach, simultaneous groups, no invalid color, 12-shot added row, danger line triggered after shot only, 24h pause then resume, seed reproducibility at 2 view sizes.
Art: 5 bubble sprites, 2–3 patterns/symbol overlays, launcher, aim path, gentle pop/fall particles, 4 backgrounds. No rig/3D.
