# ENGINE DETERMINISM LOCK V2 — DECISIONS AGENTS MUST NOT GUESS
Status: **implementation baseline for first playable build**, 2026-10-12. Supersedes ambiguous sequencing in 02/03/04/14 while preserving familiar controls, slow play and user-approved art. Numerical thresholds flagged CALIBRATE require observed tests before online Ranked freeze.

## Shared canonical state and determinism
- A run = `{mode, rulesetVersion, generatorVersion, scorerVersion, challengeId?, seed, rngState, board, nextQueue, score, turn, assists, assistLedger, completed, moveLog}`. Persist only JSON-safe integers/arrays/strings. No Date or floating point in scoring.
- Random generator: **xorshift32** on unsigned 32-bit state: `x ^= x << 13; x ^= x >>> 17; x ^= x << 5; state = x >>> 0`; reject zero by mapping seed 0 -> `0x6d2b79f5`. Every random draw consumes exactly one state transition. Bounded integer random uses modulo `nextUint32() % n`; bias accepted for cosmetic/casual but ranked test fixtures pin it; no Math.random in rules.
- Exactly one successful input = one logged action. Select/deselect/invalid taps are UI-only and never increment turn or affect RNG. Hint (if allowed) and undo are explicitly separate logged actions with rank fee. State transition is PURE, no FPS/timer dependency.
- Actions carry `runId, turnIndex, kind, payload`. Unique action ID prevents double application. Server replays with the same rules and rejects an illegal action; client never submits a trusted score.
- Serialize board in row-major order; canonical action ordering; fixed queue refill/special creation ordering. Animation starts only AFTER committing stable state; interrupted animations re-render the committed state rather than running logic twice.
- Protocol compatibility: pinned major/minor versions; published ranked seeds + rules + scoring immutable. A new scoring rule needs a new challenge namespace, not a silent patch of past standings.

## LINK — exact rules
- Board rows=8, cols=6; exterior padding one logical blank cell for routing. Only an EMPTY cell can be traversed between matching endpoints. Paths orthogonal, <=2 changes of direction. Path tie preference: **fewest bends, shortest length, row-major lexicographic path nodes**.
- Board initial fill: 24 pairs, using a selected icon palette. Identical symbol multiplicity always even. Construct backwards from a valid witness order and forward verify that witness. Generator may reject seed; no arbitrary fill advertised as verified solvable.
- On remove: remove both tiles, score `100 + (2-bends)*10`, turn++ and save.
- On deadlock: Casual lets player press Reshuffle, which reconstructs a verified-solvable remaining sub-board **preserving exact multiset** of remaining symbols and occupied-cell count; if constructive shuffle fails after a bounded search, roll back and offer Undo/Restart instead. Never lose on inactivity. Keep the original board shape/no added blockers in V1.
- Ranked assist fees: Hint -50; Reshuffle -150; Undo -100 per invocation, logged to a **non-undoable assist ledger**. Undo restores board/RNG and removes the undone scoring event but NEVER undoes any assist fee. Charge on each official assist use; score = max(0, raw pair score - cumulative fees) only at pack display; do not permit repeated undo to mint score. Hint displays an actually valid removable pair; wrong taps free.
- Ranked daily length = **one** 6x8 board; weekly length = **five** 6x8 boards (CALIBRATE daily burden with adults). Both same published seed/rules for everyone; different challenge IDs, never mix their scores. Any number of tie scores may share the same rank; do not use speed tiebreak.
- Initial generator witness proves a solution exists, NOT that all legal removal sequences succeed. QA must deliberately test mid-game deadlock recovery.

## BUBBLE — exact decisions before online freeze
- Fixed ranked logical board **7 columns** with staggered row parity 0/1 and exactly SIX logical neighbor possibilities, no diagonal square-grid logic. Renderer scales board; aiming uses same logical coordinate space on phone and tablet.
- Shot action: `{kind:"SHOOT", angleIndex: integer 0..1023}`. All collision and snap operations in canonical world-grid units, not CSS pixels; resolve ceiling or first contact, choose among valid empty attachment cells by minimum distance then row then column. Bounce against left/right walls reverses horizontal velocity. Pin a fixed collision lookup/quantized-angle solver before Ranked; any browser/server replay discrepancy BLOCKS Ranked (no approximated replay).
- Resolution sequence: (1) consume current shot from immutable queued RNG stream; (2) trace/attach; (3) same-color hex-connected component including attached bubble with size>=3 pops; (4) remove detached components not connected to top-row anchors; (5) increase shot count; (6) in Casual after every 12 successful shots, if game not cleared, prepend ONE seeded top row then check danger; (7) if clear, award clear and generate new board; if danger reached **after shot resolution**, end run with displayed PB.
- Color queue: fixed PRNG draw order and current+next two shown; when a color is absent from existing board, do not silently reroll in a device-dependent way. For MVP use a versioned deterministic `eligibleColors(sorted(current board colors))` selection rule recorded in queue; no draw during a render frame. If none are present, board-clear transition takes precedence over refilling.
- Ranked: three published boards per weekly pack, 60 valid shots **per board**, not seconds. Score: +10 popped, +30 detached, +20 per unused shot if board completely cleared. Wall-bank bonus NOT in Ranked V1 (older doc had it optional). If 60 shots or danger reached, score for current board is calculated with no unused-shot bonus; advance to next board, unless pack ended. 24-hour pause does nothing.
- Do NOT release Ranked until integer/quantized projectile simulator has 20 geometry fixtures and cross-device identical hashes. A bullet animation is only a visualization.

## JEWEL — fixed resolution order
- Official board 7x7, five symbols. Initial board and deterministic reshuffle contain no existing run of >=3 and >=1 legal swap. No timer; no loss on no legal swap.
- Valid standard swap = orthogonally adjacent cells creating an immediate horizontal or vertical >=3. If source or destination is an existing special, an adjacent swap is also valid and triggers that special (even if no 3-run). Invalid swap reverses and costs no move.
- Resolve at each cascade in deterministic stages: (1) capture all horizontal/vertical runs of 3+ BEFORE clearing; (2) union overlapping cells; (3) mark prospective special if a run length>=5 (COLOR) else >=4 (LINE), with pivot preference swapped destination if in matched cells, else smallest row-major matched cell; (4) record popped cells without clearing the chosen pivot if a new special will occupy it; (5) activate existing specials among removed cells in fixed row-major order; LINE clears pivot row (prototype), COLOR removes all jewels of color selected by swap partner or, when not provided, the lowest numbered present color; (6) cascade and gravity by columns left-to-right, cells settle from bottom up; (7) refill each column left-to-right, top to bottom consuming canonical PRNG; (8) repeat until stable. Existing LINE+COLOR swapped together: LINE then COLOR (sort by type priority and row-major); **no bonus special fusion variant in V1**.
- New specials can be activated by swapping with adjacent normal jewel; the special activates before run resolution. A created special cannot trigger on the very cascade it is minted. If two special candidates target one pivot, choose COLOR over LINE; unresolved equal priority by row-major.
- Scoring CALIBRATE before live Top: +10 each removed normal gem; additional +10 each removed at cascade depth >1; +100 when LINE activated; +200 when COLOR activated; each cell scored only once per resolution stage even when hit by overlapping specials. No unbounded recursive special creation from cleared effect cells.
- After terminal stable cascade, scan for legal swaps; if none, reshuffle deterministically consuming canonical RNG until a stable board with a legal swap is found. Bounded attempts with predefined safe permutation fallback, log reshuffle; keep score/turn unchanged. Manual invalid taps do not consume a turn. Ranked has exactly 40 VALID swaps; Casual continues indefinitely and records per-40-swap PB window.
- Required 20+ golden fixtures include crossings/overlap, 4-vs-5 priority, special+normal, special+special, multiple cascades, score de-dup, deadlock and RNG match.
