## Image types
- OBJECT: 1:1 source, desired >=1024px square when provider supports it, ONE standalone subject centrally placed within ~65% of canvas, >=16% clear margin, no floor or secondary objects, clean light neutral #E8EDE7 background or genuine alpha. The separate object will be extracted to transparent sprite.
- BACKGROUND: portrait 9:16, best provider resolution. Edge foliage/flowers, quiet central 65%, no drawn game board/phone/UI/text. Full bleed, alpha unnecessary.
- CARD/ALBUM: square illustration, small purposefully composed botanical still life, NO baked type, logo, phone, UI, badge or frame.
- POSTCARD: landscape 4:3, decorative full-scene album illustration only; never cover board or legibility. No words.

## Production flow
1. Select catalog ID; confirm applicable render provider, actual credit availability, export rights and image resolution supported. Do not use expensive 3D-model credits for 2D unless confirmed.
2. Submit exact prompt_en and aspect_ratio for ONE ID/job. Never combine 12 distinct objects into a collage and hope to crop automatically. If negative prompt field exists, use negative_prompt_en; otherwise append once to main prompt.
3. Archive original full source v001 lossless, record provider/model/job_id/actual credits/seed if available. Save revisions separately; never overwrite user-approved v001.
4. Make checkerboard alpha preview; remove neutral bg carefully with no halos; crop/center/normalize visual size and create 48px, 96px in-game previews. Render source may be 1024 but sprite should be compressed runtime texture.
5. User approves exact revision. Reject if double objects, incompatible palette, invisible parts at 48px, color-only distinction, bad anatomy, baked shadow rectangle, artifact on alpha edge, cut-off, unreadable icon or title/text.
6. Import into actual board layout, test 360px phone + 390px + tablet, optional grayscale/high contrast and reduced motion. Only then mark IN_GAME.
7. Manifest status PLANNED -> GENERATED -> REVIEW_PENDING -> USER_APPROVED -> PROCESSED -> IN_GAME. REJECTED/HOLD separate. Design approval NEVER means a source image is approved.
